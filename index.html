📚 Taxonomía de Naming Convention

Estructura del Nombre Generado

El sistema genera nombres estandarizados que incluyen información de contexto, producto, canal y oferta. Cada componente tiene un significado específico para auditoría y análisis de campañas digitales.

1️⃣ Journey Name (Nombre del Recorrido)

Formato: j{number}_{segmento}_{linea}_{producto}_{campaña}_{tipobase}_{oferta}_{canal}_{fecha}

Ejemplo: j1_per_con_cad_tyg_vf_breb_md_082026

🔹 j1: Journey Number (identificador del recorrido)
🔹 per: Segmento (Personal)
🔹 con: Línea Presupuestal (Conservación)
🔹 cad: Producto (Cuentamiga)
🔹 tyg: Campaña (Transa y Gana)
🔹 vf: Tipo de Base (Venta en Frío)
🔹 breb: Oferta (Bienvenida)
🔹 md: Canal (Medios Directos)
🔹 082026: Fecha (Agosto 2026)

2️⃣ Message Name (Nombre del Mensaje)

Formato: {segmento}_{linea}_{producto}_{campaña}_{oferta}_{medio}_{impacto}

Ejemplo: per_con_cad_tyg_breb_email_1

🔹 Identifica el mensaje específico dentro del journey
🔹 El número final indica el impacto/envío (1, 2, 3...)
🔹 Se usa en herramientas de marketing automation

3️⃣ UTM Campaign (Campaña para Analytics)

Formato: {segmento}_{linea}_{producto}_{campaña}_{tipobase}_{oferta}_{canal}

Ejemplo: per_con_cad_tyg_vf_breb_md

🔹 Se usa en parámetro utm_campaign de Google Analytics
🔹 Agrupa todos los impactos de una campaña
🔹 No incluye el número de impacto ni la fecha

4️⃣ UTM Content (Contenido para Analytics)

Formato: {segmento}_{linea}_{producto}_{campaña}_{oferta}_{medio}_{impacto}

Ejemplo: per_con_cad_tyg_breb_email_1

🔹 Se usa en parámetro utm_content de Google Analytics
🔹 Identifica el contenido/medio específico usado
🔹 Permite analizar performance por medio (email vs whatsapp vs SMS)
