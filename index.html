📚 Taxonomía de Naming Convention

Estructura del Nombre Generado

El sistema genera nombres estandarizados que incluyen información de contexto, producto, canal y oferta. Cada componente tiene un significado específico para auditoría y análisis de campañas digitales.

1️⃣ Journey Name (Nombre del Recorrido)

NBE (Especial): j{number}_{segmento}_{linea}_{campaña}_{canal}_{fecha}
COMBO: j{number}_{segmento}_{linea}_{campaña}_{canal}_{fecha}
INDIVIDUAL: j{number}_{segmento}_{linea}_{producto}_{campaña}_{tipobase}_{oferta}_{canal}_{fecha}

Ejemplo NBE Individual: j1_per_tx_nbe_viv_hipcdc_md_092026
Ejemplo NBE Combo: j1_per_tx_nbe_c_apal_apfics_apcdt_md_092026
Ejemplo COMBO: j1_per_con_tyg_md_082026
Ejemplo INDIVIDUAL: j1_per_con_cad_tyg_vf_breb_md_082026

2️⃣ Message Name (Nombre del Mensaje)

NBE Individual: {segmento}_{linea}_{campaña}_{producto}_{oferta}_{medio}_{impacto}
NBE Combo: {segmento}_{linea}_{campaña}_{combo}_{medio}_{impacto}
COMBO: {segmento}_{linea}_{campaña}_{combo}_{medio}_{impacto}
INDIVIDUAL: {segmento}_{linea}_{producto}_{campaña}_{tipoBase}_{oferta}_{medio}_{impacto}

Ejemplo NBE Individual: per_tx_nbe_viv_hipcdc_email_1
Ejemplo NBE Combo: per_tx_nbe_c_apal_apfics_apcdt_email_1
Ejemplo COMBO: per_con_tyg_c_apal_apfics_apcdt_email_1
Ejemplo INDIVIDUAL: per_con_cad_tyg_vf_breb_email_1
